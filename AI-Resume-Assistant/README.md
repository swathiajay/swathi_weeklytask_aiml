# AI Resume Assistant

## Project Overview

AI Resume Assistant is a small Generative AI project created using Claude AI. It helps a BSc Computer Science with Artificial Intelligence student generate professional resume content.

## AI Tool Used

Claude AI

## Course Connection

This project is related to Generative AI and LLM Applications.

## Objectives

- Generate a professional resume summary
- Identify technical skills
- Generate career interests
- Create a project description
- Suggest suitable entry-level job roles
- Generate interview questions

## How It Works

Student information
        ↓
Prompt Engineering
        ↓
Claude AI / LLM
        ↓
Professional Resume Content

## Technologies

- Generative AI
- Large Language Model (LLM)
- Prompt Engineering
- Claude AI

## Conclusion

This project demonstrates how Generative AI and Large Language Models can be used to assist students in creating professional resume content.
